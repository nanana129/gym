③バーベルスクワットの代替 — 3段ロケット

自宅で「担ぐ圧・全力を出し切る感覚」を作る手段は1つでは足りない。効果の大きい順に3つ重ねる。

  1. 加重リュック（最も直接的）— 本や水入りペットボトルを詰めて背負う。担ぐという行為そのものを再現できる唯一の手段。5kg から始めて 10〜15kg まで
  2. テンポ（5秒下ろす・1秒静止・爆発的に上げる）— 同じ重量でも筋肉が張力下にいる時間が3倍になる。数値より「効かせる」を重視する本人の軸に合う
  3. 片脚化（ブルガリアン）— 荷重が実質2倍近くになる。正しいフォームなら膝への負担は通常のスクワットより小さい（2026-09-03 ユーザー訂正）

「全力を出し切る」だけを取り出すなら、ウォールシットを限界まで が最も近い。金曜の最後に週1回置く。

④フォーム確認

月曜だけを撮影日にする。スマホを立てて横から1セット撮る。チェックは3点だけ。

  • 1膝と爪先の向きは揃っているか
  • 2骨盤は倒れていないか
  • 3背中は丸まっていないか

週1で見比べれば、消えたトレーナーの目の代わりになる

⑥継承元から実測したこと

  • Push : Pull = 60 : 1。評価レポートの結論は「優秀なトレーナー。ただし背中のプログラミングに盲点あり」
  • 「肩が弱い・ダンベルがぐらぐらする」の原因は肩ではなく肩甲骨の安定性（背中の筋力）不足と指摘されている
  • 重量進行の実績: スクワット 30kg → 62.5kg（4か月で倍）、デッドリフト 70kg → 75kg、ベンチプレス 32kg → 37.5kg
  • レップ範囲の配分: 1-3rep 16% / 4-6rep 21% / 7-10rep 43% / 11-15rep 18%
  • 構成比: コンパウンド 59% / ファンクショナル 14% / アクセサリー 27%

本設計が継承する原則: プログレッシブ・オーバーロード／レップ範囲の使い分け（DUP）／コンパウンド中心／少種目・高集中／RPE 7-8 で止める（あと2-3回できる余裕を残す）

本設計が埋める穴: 背中と肩甲骨。ユーザーが自ら「肩甲骨を大きく動かしたい・胸を開きたい」と希望した部位が、6年前の最大の欠落と一致した。これを第二の柱に据える。
